# 念 · 部署指南（小白版）

> 目标：不会写代码也能把「念」跑起来。  
> 仓库地址：https://github.com/xinxin240306/nian  
> 许可：个人非商业自托管可以；**禁止商用**；**禁止把修改版再公开分发**。

本文分三档，按需往下做：

1. **入门**：自己电脑上跑起来（最简单）
2. **进阶**：挂到云服务器 + 域名，手机随时打开
3. **进阶 · 小机**：接 Stack-chan（功能仍在完善，可选）

---

## 开始前你要准备什么

| 准备项 | 说明 |
|--------|------|
| 一台电脑 | Windows 最省事；也可用 Mac / Linux |
| Node.js | 建议 **18 或 20 LTS**（下面有安装方式） |
| 聊天 API | 兼容 OpenAI 格式的接口（Base URL + API Key + 模型名） |
| （进阶）云服务器 | 如轻量云 / VPS，有公网 IP |
| （进阶）域名 | 可选，但公网建议配 HTTPS |
| （小机）Stack-chan | 量产小机 + 能跑 Docker 的同一台服务器 |

> 费用提醒：模型 API、云服务器、域名都是你自己付费；本项目作者不提供免费模型额度。

# 一、入门：在自己电脑上运行（复制粘贴即可）

## 1.1 安装 Node.js（只需做一次）

1. 打开：https://nodejs.org/  
2. 下载 **LTS** 版本并安装（一路下一步即可）  
3. 装好后**关掉并重新打开**命令行窗口

验证是否成功（复制整行，回车）：

```bash
node -v
npm -v
```

能看到类似 `v20.x.x` 和 `10.x.x` 就对了。

---

## 1.2 下载源码

### 方式 A：不会用 Git（推荐小白）

1. 打开 https://github.com/xinxin240306/nian  
2. 点绿色 **Code** → **Download ZIP**  
3. 解压到例如：`D:\nian`（路径里尽量不要奇怪符号）

### 方式 B：会用 Git

```bash
git clone https://github.com/xinxin240306/nian.git
cd nian
```

---

## 1.3 启动（Windows 最简单）

1. 进入解压后的文件夹  
2. **双击** `start.bat`  
3. 第一次会自动 `npm install`，稍等  
4. 浏览器打开：**http://localhost:3000**

如果双击没反应，用「命令提示符 / PowerShell」：

```bash
cd /d D:\nian\backend
npm install
node server.js
```

把 `D:\nian` 换成你自己的解压路径。

Mac / Linux：

```bash
cd ~/nian/backend
npm install
node server.js
```

然后浏览器打开 http://localhost:3000

---

## 1.4 第一次进入 App 要填什么

1. 打开 **设置**  
2. 填写 **聊天 API**：
   - Base URL（例如中转站给你的地址，一般带 `/v1`）
   - API Key
   - 模型名（按你的服务商填写）
3. 保存  
4. 去 **角色** 创建一个角色（名字、人设随便写）  
5. 回到聊天，开始说话  

可选：在设置里再配语音（MiniMax 等）、生图接口——不配也能先纯文字玩。

---

## 1.5 常见问题（入门）

**Q：黑窗口一闪就关了？**  
A：用命令行启动（见 1.3），才能看到报错。多半是没装 Node，或没在 `backend` 目录执行。

**Q：打开网页空白 / 连不上？**  
A：确认黑窗口还在跑；地址是 `http://localhost:3000`；防火墙别拦 Node。

**Q：聊天没回复？**  
A：检查设置里的 Base URL / Key / 模型是否正确；看黑窗口有没有报错（余额不足、模型名错误很常见）。

**Q：手机怎么玩？**  
A：同一 Wi‑Fi 下，手机浏览器访问 `http://电脑的局域网IP:3000`（电脑上 `ipconfig` 看 IPv4）。  
更稳的方式见下文「进阶：VPS」。也可用仓库里的 Android 壳打包 APK（需会一点命令，见仓库 README）。

**Q：数据存在哪？**  
A：主要在 `backend/nian.db`。换电脑请连同这个文件一起拷贝（还有 `backend/uploads/` 里的图片）。

# 二、进阶：挂到云服务器（随时用手机打开）

适合：希望出门也能用、给自己一个固定网址。

下面以 **Ubuntu 系统的 Linux VPS** 为例（阿里云 / 腾讯云轻量等常见）。  
假设：

- 你已经能用 SSH 登录服务器（宝塔 / FinalShell / 终端都行）  
- 项目将放在：`/root/nian`  
- 域名你自己替换成：`your-domain.example`

> 下面命令**整段复制**，在服务器终端执行。路径按你实际情况改。

## 2.1 安装 Node.js（Ubuntu 示例）

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v
npm -v
```

## 2.2 把代码放到服务器

**有 Git：**

```bash
cd /root
git clone https://github.com/xinxin240306/nian.git
cd /root/nian/backend
npm install
```

**没有 Git、用上传：**  
把本地整个项目文件夹上传到 `/root/nian`，再执行：

```bash
cd /root/nian/backend
npm install
```

## 2.3 用 PM2 常驻运行（关机重开也会起来）

```bash
sudo npm install -g pm2
cd /root/nian/backend
pm2 start server.js --name nian
pm2 save
pm2 startup
```

最后一行若提示再执行一条命令，**把提示的那一行原样再粘贴执行一次**。

常用命令：

```bash
pm2 status
pm2 logs nian
pm2 restart nian
```

本机先测：浏览器打开 `http://服务器公网IP:3000`  
（云厂商安全组 / 防火墙要放行 **3000** 端口，或后面用 80/443 反代。）

## 2.4 站点访问锁（强烈建议）

防止链接泄露被陌生人乱进。

```bash
cd /root/nian/backend
cp .env.example .env
nano .env
```

改成你自己的（示例）：

```env
PORT=3000
SITE_LOCK_ENABLED=1
SITE_LOCK_USER=换成你的用户名
SITE_LOCK_PASS=换成你的密码
SITE_LOCK_SECRET=换成一长串随机字符
```

保存后：

```bash
pm2 restart nian
```

## 2.5 域名 + HTTPS（Nginx 示例）

先把域名 A 记录解析到服务器 IP。安装 Nginx 与证书（可用宝塔面板点几下完成；命令行示例）：

```bash
sudo apt-get update
sudo apt-get install -y nginx
```

在 Nginx 站点配置里加入反代（可用宝塔「反向代理」指向 `http://127.0.0.1:3000`）。  
核心片段示意：

```nginx
server {
    listen 80;
    server_name your-domain.example;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400;
    }
}
```

HTTPS 可用宝塔一键证书，或 certbot。配好后用手机打开：`https://your-domain.example`

## 2.6（可选）后端挂了自动重启

```bash
chmod +x /root/nian/backend/watchdog.sh
crontab -e
```

加入一行：

```cron
* * * * * /root/nian/backend/watchdog.sh >> /var/log/nian-watchdog.log 2>&1
```

# 三、进阶 · 小机（Stack-chan，可选）

> **说明**：Stack-chan 对接仍在完善中，公开版可能不稳定。  
> 详细技术文档仍在仓库 `stackchan/` 目录；下面是「按顺序做」的压缩版。

## 3.0 你需要先具备

- 第二节的念已经在 **同一台 VPS** 上用 PM2 跑着  
- 有域名，且 HTTPS 正常  
- 会一点点 Docker（或会按命令复制）  
- 手头有 Stack-chan 小机，能连 Wi‑Fi  

架构一句话：

```text
小机 ──WebSocket──► 你的域名/stackchan/ ──► MCP 网关(Docker)
                              │
                              └──► 念后端 :3000
```

## 3.1 在念网页里开桌宠

1. 浏览器打开你的念网站  
2. 进入 **toy / 桌宠** → **stackchan** 页  
3. **启用**，选择要绑定的角色  
4. **生成并复制设备令牌**（后面小机要用）  
5. MCP 工具地址（念与网关同机时）：

```text
http://127.0.0.1:8766
```

6. 公网地址填：

```text
https://your-domain.example
```

7. 保存，先在网页里点试聊，确认角色通道正常  

## 3.2 部署 MCP 网关（Docker）

仓库里有现成目录：`stackchan/mcp-vps/`。示例：

```bash
# 假设代码在 /root/nian
sudo mkdir -p /opt/stackchan-mcp
cd /opt/stackchan-mcp

# 按仓库说明复制 docker-compose 与 .env.example
cp /root/nian/stackchan/mcp-vps/docker-compose.yml ./
cp /root/nian/stackchan/mcp-vps/.env.example ./.env
nano .env
```

`.env` 里至少检查：

- 令牌与念桌宠页一致  
- 视觉等回调指到你的域名，例如：

```env
VISION_URL=https://your-domain.example/mcp/vision/explain
```

启动：

```bash
docker compose up -d
docker compose ps
```

常见端口：`8765`（给小机 WebSocket）、`8766`（给念调工具）。

## 3.3 Nginx 增加小机反代

在念的 HTTPS `server` 里增加（宝塔可加「反向代理」或自定义配置）：

```nginx
location /stackchan/ {
    proxy_pass http://127.0.0.1:8765/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 86400;
}
```

重载 Nginx：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 3.4 小机端

1. 小机 Wi‑Fi 连好网  
2. 固件 WebSocket 地址改为：

```text
wss://your-domain.example/stackchan/
```

3. 令牌填念桌宠页里的那一串  
4. 上电，看念的桌宠页是否显示在线；再试说话 / 表情  

更细的步骤、省内存建议、脸资源导入：见仓库  

- `stackchan/README.md`  
- `stackchan/DEPLOY-VPS.md`  
- `stackchan/README-mcp-nian.md`

# 四、更新版本怎么弄

以后 GitHub 有更新时：

```bash
cd /root/nian
git pull
cd backend
npm install
pm2 restart nian
```

若你是 ZIP 下载的，重新下载解压覆盖后，保留好自己的：

- `backend/nian.db`  
- `backend/.env`  
- `backend/uploads/`  

再 `npm install` + 重启。
