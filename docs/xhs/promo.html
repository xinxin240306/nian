WHAT IS NIAN

不是普通聊天机器人

角色有自己的生活、时间和节奏。你用「念」联络对方——像跨世界通讯，而不是线下见面的社交 App。

写人设、养记忆、看朋友圈、读日记、进梦境……像在和一个真实存在于另一边的人慢慢相处。
单机自托管 自备 API Key 手机网页 / Android 壳

数据在你自己的电脑或服务器上

GET STARTED

小白也能搭起来

不需要会写代码。准备一台电脑（或一台云服务器）+ 自己的模型 API Key。

1

打开 GitHub 仓库 xinxin240306/nian，下载或克隆源码

2

按《部署指南 · 小白版》一步步复制命令（Windows 可直接双击 start.bat）

3

浏览器打开 localhost:3000 → 设置里填 API → 创建角色 → 开聊

4

进阶：挂到 VPS + 域名；再进阶：接 Stack-chan 小机
