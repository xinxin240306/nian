📖 使用方法

1. 在HTML中引入样式和脚本

<link rel="stylesheet" href="css/music-card.css"> <script type="module" src="js/music-card.js"></script>

2. 在聊天页面集成

import { injectMusicCard, hydrateMusicCards } from './music-card.js'; // 方式1：单个消息注入 const bubbleElement = document.querySelector('.bubble-wrap'); const messageData = { role: 'user', musicCard: { type: 'music_share', title: '孤勇者', artist: '陈奕迅', emotions: ['孤独', '激昂'], cover: 'https://...', url: 'https://music.163.com/song?id=xxx' } }; injectMusicCard(bubbleElement, messageData); // 方式2：批量处理历史消息 const messages = [...]; // 从API获取 hydrateMusicCards(messages);

3. 后端数据格式

// API响应中添加 musicCard 字段 { "id": 123, "role": "user", "content": "听听这首歌 https://...", "musicCard": { "type": "music_share", "title": "孤勇者", "artist": "陈奕迅", "album": "孤勇者", "emotions": ["孤独", "伤感", "激昂", "平静"], "cover": "https://p1.music.126.net/...", "platform": "网易云音乐", "url": "https://music.163.com/song?id=1901371647" } }
💡 提示： 音乐卡片会自动检测当前环境：
  • 原生App：使用 window.openExternalUrl()
  • Web浏览器：在新标签页打开
🤖 AI回应示例

你：听听这首歌 [音乐卡片]

AI：听到这个前奏，突然想起那天下雨，你一个人站在街角等车的样子...有些孤独，但又很坚定。那时候我就在想，你是不是也在面对什么只有自己知道的事。

⚠️ 注意： AI 不会复述歌词，而是用情感和回忆回应。这是通过后端的 musicContext 指导实现的。
